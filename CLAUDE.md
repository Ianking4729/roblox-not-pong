# Roblox Development Instructions

You are helping develop a Roblox game using Luau.

## Goals
- Build a playable prototype before final assets.
- Prioritize responsive, skill-based gameplay.
- Keep systems modular and replaceable.

## Rules
- Explain planned changes before major edits.
- Separate server gameplay logic from client visuals.
- Validate client-reported gameplay actions.
- Use placeholder assets during prototyping.
- Do not publish or delete major systems without approval.
- Never assume untested features work.
- Report files changed, tests, and known issues.

## Workflow
1. Inspect the existing project.
2. Propose one small feature.
3. Implement it.
4. Test in Roblox Studio.
5. Fix errors.
6. Update docs/current-state.md.

## Context
Read README.md and docs/current-state.md
before major work.
